# 批次能耗联合预测区域工具

对同一生产批次**同时**预测电力、蒸汽、冷却水三类能耗，给出的是**三项一起落入**
预测区域的联合把握（三维共形预测区域），而不是给每项各自一个区间就暗示整体同样可靠。
全部数据由本地随机过程合成，无外部依赖、无网络请求。

## 快速开始

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# 方式一：网页（默认 http://127.0.0.1:8765/）
.venv/bin/python server.py

# 方式二：命令行两步
.venv/bin/python data_generation.py --out data/raw_batches.json
.venv/bin/python analysis.py            # 读 data/raw_batches.json，写 data/report.json

# 测试
.venv/bin/python test_contract.py       # 报告结构与方法论契约
node test_dom_stub.js data/report.json  # 无头 DOM 渲染/事件路径（无需浏览器）
```

页面支持：切换共形水平（80/90/95/99%）、训练/校准/检查视图切换、点击超界批次查看
偏离方向、自定义三项线性价格查看费用范围、调整样本量/漂移开关后重新生成数据、深浅色。

## 方法论与被严格遵守的边界

| 原则 | 实现位置 |
|---|---|
| 数据按**独立生产批次**划分训练/校准/检查，记录绝不跨集合 | `data_generation.generate` |
| 同批多条记录先汇总成一个批次总耗分数，**不拆开冒充独立校准样本** | `analysis.aggregate_batches`，校准集每批只贡献 1 个联合分数 |
| 预测模型（OLS 系数）与误差尺度（残差协方差）**只在训练集估计** | `analysis.fit_model` |
| 校准集只用于形成联合非一致性分数与分位 | `analysis.maha_scores` / `conformal_quantiles` |
| 小样本下所需分位超出校准记录数时，**明确声明无法给有限范围** | `k = ceil((n+1)·level) > n ⇒ finite=False`，界面禁用并展示原因 |
| 电-蒸汽近线性相关导致协方差退化，**显式处理而非静默独立化** | 特征值截断（条件数上限 1000），保留相关结构，见下 |
| 检查集同时报告**联合覆盖与各项边际覆盖**，并与朴素独立区间对照 | `analysis.evaluate_check` |
| 分布漂移时声明交换性前提变弱，**不继续宣称无条件可靠** | 漂移诊断 + `premise_status=weakened` + 页面红色预警 |
| 线性价格下的费用范围是椭球的**精确闭式投影**，非角点枚举 | `analysis.cost_ranges` |

### 联合非一致性分数与区域

每批次汇总残差 r_B（三维），分数为马氏距离

```
s(B) = sqrt(r_B' · Σ_reg⁻¹ · r_B)
```

水平 1−α 的区域是椭球 `{ r : r' Σ_reg⁻¹ r ≤ q² }`，q 取校准分数的第
`k = ceil((n+1)(1−α))` 个顺序统计量。交换性成立时，有限样本保证覆盖率不低于
`k/(n+1) ≥ 1−α`。

**联合判定用马氏距离本身（score ≤ q）**，不能用椭球在坐标轴上的投影拼成外接盒——
外接盒严格大于椭球，用它判定会系统性虚高联合覆盖（本仓库早期版本即犯此错，已修正并加测试）。

### 协方差退化的显式处理

合成数据中蒸汽与电力近线性（r≈0.97），残差协方差条件数约 6×10⁴，最小特征值方向
数据几乎不提供信息。直接求逆会放大噪声。处理方式：

- 对特征值设下限 `λmax / 1000`（条件数上限），**保留特征向量与相关结构**；
- 被截断的特征方向（主导变量、特征向量、原始/下限特征值）在页面第 2 节完整披露；
- **不做对角化**——那等于把三项误差当成互相独立，正是本工具要避免的错误假设。

页面同时展示残差相关矩阵，近线性对以红色标出，处理方法与拒绝独立化的理由写在面板上。

### 为什么"各项各自区间"不可靠

朴素做法给每项一个一维共形区间，三项独立时其联合名义覆盖仅为 `level³`
（如 90% 水平 → 0.9³=72.9%）；而实际误差强相关且存在漂移，朴素盒子的真实联合覆盖
更低（本数据 90% 水平下仅约 40%）。页面第 4 节并排呈现联合椭球覆盖、各项边际覆盖、
朴素盒子覆盖与独立假设的名义联合值，差异一目了然。

### 漂移场景

默认在检查集注入渐增漂移（蒸汽基线抬升、电力爬升，冷却水不漂移）。此时：

- 各项边际覆盖可能仍接近名义值（单项看"还行"），但**真实联合覆盖大幅跌破名义**；
- 漂移诊断标出标准化平均残差偏移超过 1σ 的变量；
- 页面明确写出：历史覆盖率只描述当前检查集事实，不能外推为未来批次的无条件保证，
  应重新校准或更新模型。
- 关闭漂移（`--no-drift` 或界面取消勾选）后，多种子验证联合覆盖均不低于名义值，
  确认方法在前提成立时确实有效。

## 费用范围公式

对线性价格向量 p，椭球上费用 `p'(μ+r)` 的范围有闭式解：

```
中心 = p'μ，半宽 = q · sqrt(p' Σ_reg p)
```

朴素盒子（把三项当独立取角点）半宽为 `q · Σ_j |p_j| · sqrt(Σ_jj)`，由柯西-施瓦茨
不等式恒有盒子半宽 ≥ 椭球半宽，页面同时给出两者及"盒子/联合 半宽比"。
